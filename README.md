**AI-Powered Telegram Content Automation**



An automation pipeline that combines AI vision, natural language generation, and Telegram API to automatically create and publish Persian educational technology content.



**Problem**



**Managing educational technology content manually requires time for:**



\- Writing captions

\- Selecting images

\- Formatting posts

\- Publishing consistently



**Solution**

This system automates the entire workflow using Gemini AI and Telegram Bot API.
